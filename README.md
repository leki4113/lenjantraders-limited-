# Lenjan Traders Limited Website

A responsive company website / online-shop starter for **Lenjan Traders Limited**.

## Files

- `index.html` — website structure and content
- `style.css` — responsive design and styling
- `script.js` — mobile menu and WhatsApp ordering

## Before publishing

Open `script.js` and replace:

```text
254700000000
```

with the company's real WhatsApp number in international format.

Also update the phone number and email in `index.html`.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `lenjan-traders-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the public website address.
